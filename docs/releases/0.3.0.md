# SnipShelf 0.3.0

SnipShelf 0.3.0 brings color palettes to your references, faster ways to collect
cutouts, and search, backup, and recovery for your library.

## What's new

- **Colors beside your images.** Previews and pinned images show proportional
  color palettes. Click a swatch to copy its HEX, analyze the subject or the
  whole image, adjust the color limit and shade merging, and save your defaults.
- **Capture without breaking your flow.** Rectangle joins Lasso and Polygon,
  with customizable global shortcuts for each tool. Choose a destination group
  and use **Keep & Continue** to collect multiple cutouts from one frozen image.
- **Touch up directly in Capture Preview.** Restore and Erase brushes, zoom,
  pan, undo/redo, and Original/Cutout comparison share one resizable window.
  Background removal focuses on the selected area, and unfinished captures
  remain available when you switch apps or invoke Capture again.
- **Find and recover your references.** Search image and group names across the
  library. Recently Deleted keeps removed images until you restore or permanently
  delete them. Back up the library as a Finder package and restore it with a
  recoverable copy of the previous library.
- **Arrange your workspace.** Dedicated card handles support persistent shelf
  ordering and pulling out floating references. New reference windows appear
  beside the Shelf, and Close All controls are available in each window. Shelf
  resizing, docking, search, and compact preview controls adapt to available space.
- **A clearer first look.** The README now shows four HTML recreations of the
  interface, with a local interactive preview and a separate development guide.

## Download and upgrade

`SnipShelf-0.3.0-arm64.zip` requires **Apple Silicon and macOS 26 or newer**.
Quit SnipShelf, unzip the download, replace `SnipShelf.app` in Applications, and
reopen it. Existing clips stay in local storage.

The library index upgrades to **version 3** on the next edit. Version-1 and
version-2 libraries load directly, preserving the original PNGs. Older app
releases cannot read the upgraded index: copy
`~/Library/Application Support/SnipShelf/` before upgrading if you may need to
return to an older release.

The app is **ad-hoc signed and not notarized**. If macOS blocks the first launch
and you trust the download, open it once, then use **System Settings → Privacy &
Security → Open Anyway**. See [Apple's instructions](https://support.apple.com/102445).
Screen capture also requires screen-recording permission; image import and
Crop a Copy work without it.

Download both release assets into the same folder and verify the ZIP with:

```sh
shasum -a 256 -c SnipShelf-0.3.0-arm64.zip.sha256
```

## Validation

GitHub Actions runs the full Swift test suite on macOS 26 before building this
release. Packaging checks version 0.3.0/build 4, arm64 architecture, the exact
bundle contents, common private build paths, and the extracted ad-hoc signature.
The ZIP and its verified SHA-256 are uploaded before the release is published.

Physical mouse/trackpad feel, the complete screen-recording permission flow,
and downloaded-app Gatekeeper handling still need manual verification. See the
[usage guide](https://github.com/0xH4KU/SnipShelf/blob/v0.3.0/docs/usage.md) and
[validation notes](https://github.com/0xH4KU/SnipShelf/blob/v0.3.0/docs/validation.md).
