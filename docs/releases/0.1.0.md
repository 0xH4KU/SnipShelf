# SnipShelf 0.1.0

The first release of SnipShelf: a native macOS shelf for transparent cutouts and
visual references, processed and stored entirely on your Mac.

- Capture part of the screen or import an image, then select with a freehand
  lasso or polygon. Compare the original and cutout, refine, undo, and keep it.
- Keep clips in a floating shelf that tucks against either screen edge.
  Preview, zoom, copy, drag, export, and delete multiple clips with undo.
- A new sticker app icon and matching monochrome menu-bar icon.
- No account, analytics, subscription, or third-party dependencies. MIT licensed.

## Download and install

`SnipShelf-0.1.0-arm64.zip` requires **Apple Silicon and macOS 26 or newer**.
Unzip it, move `SnipShelf.app` to Applications, and open it. The app lives in the
menu bar. Start a screen capture with **Command–Shift–2**, then grant screen
recording permission when prompted. Image import needs no capture permission.

The app is **ad-hoc signed and not notarized**. Its signature contains no
developer certificate or Team ID. If macOS blocks the first launch and you trust
the download, use **System Settings → Privacy & Security → Open Anyway**.
[Apple explains this exception](https://support.apple.com/102445); managed Macs
may restrict it. Building from source is also supported.

The companion `.zip.sha256` file checks download integrity:

```sh
shasum -a 256 -c SnipShelf-0.1.0-arm64.zip.sha256
```

## Known limits

This is an early release. Automated checks ran on Apple Silicon with macOS 27;
macOS 26 runtime, Intel hardware, the downloaded-app Gatekeeper flow, and the
complete screen-capture permission flow have not yet been verified. Trackpad
feel, multiple displays, and external drag/drop need broader manual testing.
Large image writes can briefly block the interface. Selection assistance is
conservative and does not perform automatic background removal.

See the [usage guide](../usage.md) and [validation notes](../validation.md).
