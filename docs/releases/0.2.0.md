# SnipShelf 0.2.0

SnipShelf 0.2.0 adds reference groups, independent floating image windows, and
more control over capture and organization.

## What's new

- **Groups and floating references.** Organize related clips into groups, drag
  clips between them, and pull out a group or pin an individual image above your
  other apps. Each reference remembers its window position and size; pinned
  images also remember their own Checkerboard, Light, or Dark background.
- **Pick up where you left off.** The Shelf and each group remember selection
  and scroll position during the session, including after tucking and reopening
  the Shelf. Keyboard selection brings offscreen images into view.
- **Undo your organization.** Command–Z now restores moves, group creation and
  dissolution, image and group renaming, and deletions. Images captured or
  imported after the operation are preserved. Select an image and press Return
  to rename it, or use its context menu.
- **More deliberate docking.** Drag at least one third of the Shelf's width
  beyond either screen edge before the tuck preview appears. Release to tuck;
  move back inside the threshold to cancel.
- **Better cutouts.** Native subject masking removes backgrounds inside your
  selection. Restore and Erase brushes let you touch up the result, with zoom,
  pan, stroke undo/redo, and a guide showing removed pixels. Remove Background
  can be switched off to keep the original selection.
- **Smoother drawing and clearer controls.** Fluid lasso drawing adds adaptive
  steadiness and closing assistance. The Shelf, capture review, and image preview
  use refined native controls, clearer actions, accessible shortcut recording,
  and copy confirmation that follows the most recently copied image. Imported
  and dropped images retain their original names.

## Download and install

`SnipShelf-0.2.0-arm64.zip` requires **Apple Silicon and macOS 26 or newer**.
Quit SnipShelf, unzip the download, replace `SnipShelf.app` in Applications, and
reopen it. Existing clips remain in local storage.

The app is **ad-hoc signed and not notarized**, with no developer certificate
or Team ID. If macOS blocks the first launch and you trust the download, use
**System Settings → Privacy & Security → Open Anyway**.
[Apple's instructions](https://support.apple.com/102445) explain this exception.
Screen capture also requires screen-recording permission; importing images and
Crop a Copy do not.

Groups use version 2 of the local shelf index. Existing version-1 shelves load
directly and upgrade on the next edit, without changing the original PNGs.
Older releases cannot read the upgraded index; back up the storage folder before
downgrading. Undo history and browsing position last for the app session.

Verify the download with its companion checksum file:

```sh
shasum -a 256 -c SnipShelf-0.2.0-arm64.zip.sha256
```

## Validation

The 57-test suite covers capture review, mask touch-ups, storage and recovery,
group organization, native reference-window interactions, navigation memory,
docking thresholds, and interface rendering. The release ZIP is checked for
version 0.2.0/build 3, arm64 architecture, expected contents, common local build
paths, and a valid extracted ad-hoc signature.

Tests run on Apple Silicon with macOS 27. Physical mouse/trackpad feel, the full
screen-recording permission flow, macOS 26 runtime, and downloaded-app Gatekeeper
handling still need manual verification. Cached native renders do not reproduce
compositor-backed glass exactly. See the [usage guide](../usage.md) and
[validation notes](../validation.md).
